# AI Lead Generation & Qualification Automation

AI-powered automation system built with n8n for lead generation, website data extraction, and AI-based lead qualification.

## 🎯 Project Overview

This project automates the process of discovering potential business leads, collecting relevant website information, and transforming raw data into structured and qualified lead information.

## ⚙️ Key Features

- Lead generation
- Website data extraction
- Website filtering
- Duplicate removal
- HTML processing
- AI-powered lead analysis
- Lead qualification
- Structured lead data
- CRM / Google Sheets integration

## 🛠️ Technologies

- n8n
- AI / LLM
- HTTP Requests
- Web Scraping
- Data Processing
- Google Sheets
